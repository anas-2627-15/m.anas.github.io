##  Learning Database Systems with MySQL

## Introduction
Learned how to manage and store data using MySQL.

## Learning Through Practice
- Created databases and tables
- Used SQL queries (SELECT, INSERT, UPDATE, DELETE)

## SQL Example
```sql
CREATE DATABASE student_db;

CREATE TABLE students (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    age INT
);

INSERT INTO students VALUES (1, 'Anas', 20);

SELECT * FROM students;
```
