#  Machine Learning (Model Training)

## Introduction to Machine Learning and Model Training

### Introduction

As I progressed in my studies, I was introduced to Machine Learning, which focuses on training models to make predictions from data. This was one of the most exciting parts of my journey because it combines programming, mathematics, and real-world problem solving.

### Learning Through Practice

I worked on a dataset related to Walmart weekly sales prediction. Using Python libraries such as pandas, matplotlib, seaborn, and scikit-learn, I performed data preprocessing, visualization, and model training.

I learned how to clean data, handle missing values, and understand patterns using graphs. This helped me prepare the dataset for training machine learning models.

### Code Implementation

I used Decision Tree and Random Forest models for prediction:

- Data preprocessing using pandas  
- Visualization using matplotlib and seaborn  
- Model training using scikit-learn  
- Model saving using joblib  

### Explanation

The model was trained using historical sales data to predict future sales. Random Forest performed better due to its ability to handle complex patterns and reduce overfitting.

### Reflection

This experience helped me understand how machine learning models are built and evaluated. It improved my analytical thinking and gave me confidence to work on real-world datasets.
