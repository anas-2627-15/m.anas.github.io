# My First Experience with Python and Building Basic Logic

In my first semester as a Computer Engineering student, I was introduced to Programming Fundamentals (PF), where I started learning Python. At the beginning, everything felt new and confusing because I had no prior programming background. Writing even a simple program required a lot of effort, and I often struggled with syntax errors and logical mistakes. However, with continuous practice in lab sessions and assignments, I gradually started understanding how programming actually works.

## Learning Through Practice
During my learning process, I covered basic concepts such as variables, conditional statements, loops, and functions. These concepts helped me build the foundation of programming. One of the most interesting and practical programs I developed was a discount calculator system. This program was not just a basic task, but it also included multiple conditions and a lucky draw feature, which made it more engaging and closer to a real-world scenario.

While working on this program, I realized that programming is not about memorizing code but about applying logic step by step. Each condition I added improved my understanding of decision-making in programs. I also learned how small changes in logic can affect the entire output.

## Code Implementation
```python
def calculate_discount():
    name = input("Enter your name: ")
    age = int(input("Enter your age: "))
    amount = 1800  

    if age >= 18:
        discount = 20
    elif 13 <= age <= 17:
        discount = 10
    else:
        discount = 5

    if age >= 18:
        choice = input("Enter lucky draw? (yes/no): ").lower()
        if choice == "yes":
            if age % 2 == 0:
                discount += 10
            else:
                discount += 5

    final_amount = amount - (amount * discount / 100)

    print(f"{name}, Discount: {discount}%")
    print(f"Payable Amount: {final_amount}")

calculate_discount()
```
 This code is available on my GitHub repository.

## Explanation

This program combines multiple programming concepts, including conditional statements, user input handling, and arithmetic operations. The lucky draw feature adds an extra level of complexity, making the program more interactive. By working on this task, I understood how real-world systems apply similar logic to provide dynamic results based on user input.

## Reflection

Overall, this experience played an important role in developing my logical thinking and problem-solving skills. It gave me confidence in writing programs independently and helped me understand the importance of practice and consistency. This was a significant step in my journey as a Computer Engineering student.

## Code Implementation

```
def check_numbers():
    total = 0

    for i in range(3):
        num = int(input(f"Enter number {i+1}: "))

        if num % 2 == 0:
            print(f"{num} is Even")
        else:
            print(f"{num} is Odd")

        total += num

    print(f"Total sum: {total}")

check_numbers()
```

## Code Implementation
```
using System;

class Student
{
    public string name;
    public int age;

    public void display()
    {
        Console.WriteLine("Name: " + name);
        Console.WriteLine("Age: " + age);
    }
}

class Program
{
    static void Main()
    {
        Student s1 = new Student();
        s1.name = "Anas";
        s1.age = 20;

        s1.display();
    }
}
```
 This code is available on my GitHub repository.

## Explanation

This program shows how a class is created and how an object is used to access its data and methods. It helped me understand how real-world entities can be represented in programming using object-oriented concepts.
